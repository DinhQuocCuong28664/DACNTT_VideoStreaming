\chapter{Environment Variables Reference}
\label{app:env}

Terraform sets every variable below when it creates the functions and the job definitions, so none is
typed by hand in a deployed environment. Values that are secret are not environment variables at all:
the API and the workflow functions read them from AWS Secrets Manager at start-up, and only the
identifier of the secret is passed in the environment. Table~\ref{tab:env-vars} lists the variables by
the part that reads them, and Table~\ref{tab:env-secret} the fields of the secret of the API.

At minimum, the API needs the variables marked as required and the three required fields of its secret.
Playback needs the CloudFront key pair, Google sign-in needs the client identifier on both the API and
the web build, and e-mail needs the mail account. The pipeline runs without any of the optional values;
screening is on unless it is switched off explicitly.
