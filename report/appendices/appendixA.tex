\chapter{Complete REST API Reference}
\label{app:api}

This appendix lists every route of the API, grouped by the feature that registers it; Table~\ref{tab:api-routes}
in Section~\ref{sec:api-design} gives the same groups in brief. Every path below is served under the prefix
\texttt{/v1}, reached through the Cloudflare Worker, and every request and response body is JSON. An error
always has the shape \texttt{\{error:\{code,message\}\}}, where the code is a stable identifier such as
\texttt{EMAIL\_NOT\_VERIFIED}, \texttt{VIDEO\_UNDER\_REVIEW} or \texttt{RATE\_LIMITED} that the interface
reacts to, and the message is text for the viewer. Listings are paged with an opaque cursor.

The access column uses five levels. \textit{Public} routes answer without a session, under the access rule
of Section~\ref{sec:content-protection} wherever a video is involved. \textit{Signed in} routes need a bearer
token, and where a route changes a resource, the API also checks that the requester owns it.
\textit{Playback token} routes need the short token issued with a playback grant, so that an embedded player
can use them without a session. A permission name, such as \texttt{moderation:review}, means a staff role
that holds it (Table~\ref{tab:permissions}). Routes marked \textit{limited} have their own rate limit on top of
the global one of 300 requests a minute.
